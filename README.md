# 📦 Sistema de Controle de Estoque 

> Um projeto em Python para gerenciamento de produtos e prática de lógica de programação


## 📌 Sobre o projeto

Este projeto foi desenvolvido em Python para praticar lógica de programação e gerenciamento de dados.

O sistema permite cadastrar, consultar, editar e excluir produtos, além de calcular o valor total do estoque.

## 🛠️ Tecnologias utilizadas

- Python 
- JSON para armazenamento de dados
- Visual Studio Code para desenvolvimento

## ✨ Funcionalidades

- 📌 Cadastro de produtos com nome, quantidade e preço
- 🔎 Consulta de produtos pelo nome
- ✏️ Edição de produtos com confirmação
- 🗑️ Exclusão de produtos com confirmação 
- 📋 Listagem completa de estoque
- 💰 Cálculo do valor total de cada produto e do estoque
- 💾 Salvamento dos dados em arquivo JSON
- ✅ Validação dos dados informados pelo usuário

## 🚀 Como executar o projeto 

1. Instale o Python no seu computador.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no Visual Studio Code.
4. Execute o seguinte comando no terminal:

   ```bash
   python main.py
   ```
